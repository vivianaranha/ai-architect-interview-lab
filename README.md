# AI Architect Interview Lab

A hands-on preparation repository for **AI Architect, GenAI Architect, Enterprise AI Architect, AI Solutions Architect, Forward Deployed AI Architect, Principal AI Engineer, and Staff AI Engineer** interviews.

The goal is not to memorize products. It is to learn how to turn ambiguous business problems into **secure, scalable, governed, observable, cost-aware AI systems** and explain the trade-offs clearly.

## Included

- **120+ interview questions with model answers**
- **20 system-design case studies**
- **15 whiteboard architecture challenges**
- **10 full mock interview packets**
- **30-day preparation plan**
- RAG, agents, model routing, security, governance, evaluation, enterprise integration, data, cloud/hybrid, reliability, and cost
- Architecture decision, threat-model, discovery, and scoring templates
- Runnable random mock-interview CLI
- Mermaid reference architectures

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python 18-tools/mock_interview.py
```

## Recommended answer framework: SCOPE

1. **S — Situation and stakeholders**
2. **C — Constraints and success criteria**
3. **O — Options and architecture**
4. **P — Production concerns**
5. **E — Evaluation and evolution**

Do not start a system-design interview by naming an LLM, vector database, or agent framework. Start with the business workflow, users, constraints, and measurable outcome.

# AI Architecture Interview Anti-Patterns

1. Starting with a vector database.
2. Saying “use the biggest model” without evaluation.
3. Putting critical business rules only in prompts.
4. Letting the LLM authorize actions.
5. Using multi-agent architecture by default.
6. No evaluation plan.
7. Ignoring failure modes.
8. Ignoring cost.
9. Treating governance as documentation only.
10. Forgetting rollout and operations.
